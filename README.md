# Cuestionario de Sistemas 2026

Sitio de estudio interactivo con 828 preguntas organizadas en 21 materias.

## Uso local

Abre `index.html` en un navegador moderno.

## Publicación

El sitio se publica en GitHub Pages mediante el workflow de GitHub Actions incluido en `.github/workflows/pages.yml`.

## Aviso de privacidad

Este repositorio es público. El banco de preguntas y las respuestas de `preguntas.js` y `respuestas.js` pueden ser inspeccionados y descargados por cualquier persona. Los documentos fuente PDF/DOCX no forman parte de este repositorio.
